
             STACKWISE – FULL STACK DEVELOPMENT QUIZ

1. PROJECT OVERVIEW
-------------------
StackWise is an interactive online quiz system designed to
test and improve knowledge of Full Stack Development.

The application contains topic-wise sections covering the
major areas of full stack development. Users can take the
complete assessment or practice individual sections and
view their performance through visual accuracy reports.

The project is developed using HTML, CSS and JavaScript and
runs directly in a web browser without requiring a server.

6. HOW THE QUIZ WORKS
---------------------
The user can choose between:

A. Full Assessment
   - Contains all 75 questions.
   - Covers every Full Stack Development topic.

B. Topic Assessment
   - Contains 15 questions from the selected topic.
   - Useful for focused practice.

During the quiz, users can:
- Select answers
- Move between questions
- Jump directly to a question
- Track answered questions
- Monitor the remaining time

After completing the quiz, the system displays:
- Total score
- Accuracy percentage
- Number of correct answers
- Time taken
- Topic-wise performance
- Recommended topic for further practice

8. SCORING SYSTEM
-----------------
The accuracy is calculated using:

        Accuracy = (Correct Answers / Total Questions) × 100

Example:

If a user answers 12 out of 15 questions correctly:

        Accuracy = (12 / 15) × 100
                 = 80%

The result dashboard displays the performance
visually using charts and progress bars.
